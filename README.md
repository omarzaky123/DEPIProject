# DEPIProject  

## Project Overview  
This is a multi-layered **E-Commerce project** built with **ASP.NET Core API** (backend) and **ASP.NET Core MVC** (frontend).  
The frontend communicates with the backend using **HttpClient**, and the solution follows a **4-layer architecture** for scalability and maintainability.  

- **Entity Layer** → Defines entities and models.  
- **DAL (Data Access Layer)** → Generic Repository + Unit of Work with EF Core.  
- **API Layer** → REST API with AutoMapper and ASP.NET Identity.  
- **MVC Layer** → ASP.NET MVC frontend consuming the API.  

## Key Features  
- Clean 4-layer architecture.  
- Generic Repository & Unit of Work patterns.  
- AutoMapper for mapping DTOs and entities.  
- ASP.NET Identity for authentication and authorization.  
- API consumed via HttpClient in MVC frontend.  

## Technologies Used  
- ASP.NET Core Web API  
- ASP.NET Core MVC  
- Entity Framework Core  
- AutoMapper  
- Identity  
- SQL Server  
- HttpClient
